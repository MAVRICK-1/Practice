**Platform Used:**  
Cloud-based platform with integration on AWS for production and Vercel for development, with Google Cloud as an alternative for cloud services.

**Deployment and Process:**  
The project uses Docker for containerizing applications, ensuring consistent environments across development, testing, and production. Kubernetes orchestrates these containers, managing deployment, scaling, and operations. AWS provides the necessary cloud infrastructure for hosting backend services in production, while Google Cloud is an alternative option for cloud services. Vercel is used for deploying the frontend application during development. The deployment process is automated using GitHub Actions, which handles continuous integration and continuous deployment (CI/CD). This setup ensures that every code change is automatically tested and deployed, maintaining a robust and reliable application.

**Project Abstract:**  
The project is an Open Network for Digital Commerce (ONDC) site integrated with OpenStreetMap, aiming to provide a seamless digital commerce experience for businesses and consumers across Bharat. Leveraging ONDC APIs, the platform ensures robust data exchange and integration with various digital commerce services. Technologies used include React, TypeScript, Tailwind CSS, Material-UI, Firebase, Docker, Kubernetes, AWS, Vercel, and Stripe for payment integration.
